## Connecting to the hosted service

The reference above is the whole API — the same calls run against the hosted service
(Infino Cloud). You point `connect` at an `https://<host>/<database>` URL and pass an
API key; every table and search call after that is identical to local use. The hosted
transport is enabled slightly differently per language:

<CodeGroup>

```python Python icon="python"
# Built in — nothing to enable.
import infino

db = infino.connect("https://api.platform.infino.ai/my-app", api_key="inf_…")
```

```typescript Node.js icon="node-js"
// Built in — nothing to enable.
import { connect } from "@infino-ai/infino";

const db = connect("https://api.platform.infino.ai/my-app", { apiKey: "inf_…" });
```

```toml Rust icon="rust"
# Rust opts in via the `remote` feature.
[dependencies]
infino = { version = "0.1", features = ["remote"] }
```

</CodeGroup>

The API key can be passed to `connect` or read from the `INFINO_API_KEY` environment
variable. For the full walkthrough and the credential model, see the hosted
[Quickstart](/cloud/quickstart) and [Authentication](/cloud/authentication).

## REST API

Not using one of the SDKs? The hosted service is also a plain HTTP API — the same
per-database operations (tables, rows, search, SQL) over REST. See the **REST API**
section in this tab.

The machine-readable OpenAPI 3.1 spec is served at
[`https://api.platform.infino.ai/openapi.json`](https://api.platform.infino.ai/openapi.json) —
point your code generator or client tooling at it as the source of truth.

## Local vs hosted

The SDKs connect to both local and hosted Infino with the same calls. For the
exact list of where the two differ — the handful of local-only and hosted-only
operations — see [Local vs hosted](/api-reference/parity).
