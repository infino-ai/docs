Infino is built for query **speed per dollar** on object storage: fast warm queries
without paying for always-on provisioned capacity.

## Engine performance

The hosted service runs the same engine as the open-source library, so its query
performance starts from the engine's published benches. For example, a warm single-term
BM25 query on a 1-million-document index returns in the **microsecond range** once the
query's byte ranges are cached. These are the engine's own measurements, not hosted
end-to-end numbers.

The full methodology and numbers live in the open-source benchmarks:
[`benches/README.md`](https://github.com/infino-ai/infino/blob/main/benches/README.md).
See also [Tradeoffs](/tradeoffs) for what the object-storage-native design optimizes for.
