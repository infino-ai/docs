Infino retrieves from the same table several ways. Every search returns Arrow rows; pass
a **`projection`** to choose which columns come back — `_id`, any scalar column, or the
trailing `score` (omit it for just `_id` + `score`, the cheapest).

<Tip>
Always pass a sensible top-`k` on production queries — it bounds both the work and the
result size.
</Tip>
