How to do specific things with Infino. Examples are in Python, Node.js, and Rust. The
Rust snippets assume a `db` connection and a `docs` table (see the
[Quickstart](/quickstart)), build rows as Arrow `RecordBatch`, and use `?` for errors —
full API on [docs.rs](https://docs.rs/infino).
