Infino stores your data as Apache Parquet on object storage and runs search directly
on it. Two layers do the work:

- **Superfile** — a single Parquet file with embedded BM25 and vector (IVF + RaBitQ)
  indexes spliced in. Immutable once written.
- **Supertable** — composes many superfiles into a queryable table with
  snapshot-isolated reads, append-only writes, and an atomic-commit manifest.

There's no server, daemon, or managed service — Infino runs in-process.
